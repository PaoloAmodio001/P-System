# P-System Lean Formalization

This directory contains the machine-checkable foundation of the
P-System formal model.

The initial objective is deliberately conservative:

1. define the mathematical objects;
2. state invariants;
3. prove elementary lemmas;
4. prove safety theorems;
5. establish correspondence with the executable implementation.

A Lean definition is not evidence that the corresponding theorem
has already been proved.

Only declarations accepted by the Lean kernel count as
machine-checked proofs.
